Critical Architecture Rules
Database

Only ONE Base.

from app.db.base import Base

Never create another Base.

Only ONE engine.

create_engine(...)

must exist only in:

app/db/session.py

Never create duplicate engines.

Config

Single source of truth:

app/config/settings.py

Exports through:

app/config/__init__.py

Keep compatibility with imports such as:

from app.config import JWT_SECRET

Do not introduce:

config.py

outside the package.

Redis

Direct Redis access allowed only in:

app/core/redis.py
app/auth/utils.py

Services and routes must not import Redis directly.

Auth

Do not redesign authentication.

Auth foundation is complete and considered stable.
